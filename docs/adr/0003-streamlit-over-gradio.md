# Streamlit вместо Gradio для интерфейса Operator

Интерфейсу нужны список Account с их состояниями, формы создания и правки, пошаговый мастер
входа в MAX (запрос кода, ввод кода, иногда пароль 2FA, обратный отсчёт) и журнал событий.
Streamlit сделан под такие админки: формы, таблицы, многостраничность и `st.session_state`
для незавершённого мастера. Gradio построен вокруг схемы «вход → функция → выход» для демо
ML-моделей; таблицы с действиями и многошаговые сценарии там собираются из `gr.State`
и выглядят чужеродно.

## Considered Options

- Gradio: единственный плюс, встроенная basic-auth, перекрывается паролем в Streamlit
  и reverse proxy сервера.
- Обычный веб-фреймворк с шаблонами: больше кода ради двух Account, а заказчик просил
  выбрать из Streamlit и Gradio.

## Consequences

- Streamlit сам не держит соединения с MAX и Telegram: вся работа в `bridge`, UI только
  клиент API (см. ADR-0001).
