# Max-gate

Шлюз, который двусторонне переносит переписку между мессенджером MAX и Telegram: каждый чат MAX
отражается в отдельный топик у Telegram-бота, а ответы из топика уходят обратно в MAX.
Один экземпляр обслуживает несколько людей, у каждого свой номер MAX и свой бот.

## Language

Термины записаны по-английски, как они называются в коде; определения по-русски.

### Участники

**Gate**:
Работающий экземпляр приложения. Обслуживает несколько независимых Account.
_Avoid_: bridge, сервер, инстанс

**Account**:
Связка одного аккаунта MAX (номер телефона) с одним Telegram-ботом, принадлежащая одному Owner.
_Avoid_: bridge, tenant, связка, пользователь

**Owner**:
Пользователь Telegram, которому принадлежит Account. Бот этого Account разговаривает только
с Owner. Их может быть несколько: основной Owner (его личный чат становится Inbox в режиме
private) и дополнительные, которые работают с Account в режиме supergroup.
_Avoid_: user, admin, хозяин

**Operator**:
Человек, который управляет всеми Account через веб-интерфейс Gate: заводит их, проводит вход
в MAX, следит за состоянием.
_Avoid_: admin, администратор

### Сторона MAX

**MaxChat**:
Любая переписка на стороне MAX. Бывает трёх видов: Dialog, Group, Channel.
_Avoid_: чат, беседа

**Dialog**:
MaxChat один на один между Owner и другим человеком.
_Avoid_: direct, директ, личка, DM

**Group**:
MaxChat с несколькими участниками, где все могут писать.
_Avoid_: chat (так группа называется в PyMax), беседа

**Channel**:
MaxChat, в котором пишет только владелец канала, остальные читают. По умолчанию не отражается.

**Session**:
Авторизация Account в MAX: токен входа и идентичность устройства. Живёт, пока MAX её не отзовёт.
_Avoid_: token, login

### Сторона Telegram

**Inbox**:
Чат в Telegram, внутри которого живут Topic одного Account: либо личный чат Owner с ботом,
либо приватная супергруппа-форум.
_Avoid_: group, forum, home chat, основной чат

**Topic**:
Тема внутри Inbox, отражающая ровно один MaxChat. Название при создании берётся из MaxChat,
дальше Owner волен его менять.
_Avoid_: thread, тред, диалог с ботом

### Связи

**ChatLink**:
Соответствие между одним MaxChat и его Topic. Помнит, переименовал ли Owner тему сам и заглушена
ли она.
_Avoid_: mapping, binding, привязка

**MessageLink**:
Соответствие между сообщением MAX и его отражением в Telegram (или наоборот). Нужно для ответов,
правок, удалений и распознавания Echo.
_Avoid_: mapping

**Muted**:
Состояние ChatLink, в котором сообщения из MaxChat не переносятся в Topic, но ChatLink сохраняется.
_Avoid_: disabled, ignored, отключён

### Перенос сообщений

**Relay**:
Перенос одного сообщения с одной стороны на другую с сохранением смысла: текст текстом, фото
фото, голосовое голосовым.
_Avoid_: forward, пересылка (в обоих мессенджерах это отдельная функция «переслать сообщение»)

**Fallback**:
Relay содержимого, для которого нет аналога на другой стороне: файлом или текстовой заметкой.
_Avoid_: degradation

**Echo**:
Событие MAX о сообщении, которое Gate сам только что отправил из Topic. Не подлежит Relay.
_Avoid_: duplicate, loop

**Catch-up**:
Relay сообщений MAX, накопившихся за время, пока Account был отключён от MAX.
_Avoid_: backfill, sync, история

**Note**:
Служебное сообщение Gate в Topic или Inbox: об ошибке, пропущенных сообщениях, слишком большом
файле, отозванной Session.
_Avoid_: notification, alert, system message
